# 2026-10-20

## file-j（macOS 12 双栏文件管理器）—— 主体完成

技术栈：Tauri 2 壳（Rust 仅框架）+ Vue 3 / Tailwind 3.4 / TS 前端 + Go 1.26.9 sidecar 业务后端；
前后端通过 loopback WebSocket JSON-RPC 通信；全部持久化走 YAML（无数据库）。

### 关键决定
- **交互方式**：Go 后端由 Rust 以 sidecar 方式拉起，绑定 `127.0.0.1:0`，首行 stdout 输出握手 JSON
  `{type:"ready",port,token,...}`；前端用 token 连 `/ws`。不把业务路由放进 Rust（否则 Rust 承担业务）。
- **统一文件抽象**：`fsx.Provider`（Stat/List/Open/Create/MkdirAll/Remove/Rename/Chmod/Chtimes/Home）
  本地盘与 SFTP 同一接口，传输引擎因此只有一份代码覆盖 本地↔本地 / 上传 / 下载。
- **第三方库**：`golang.org/x/crypto/ssh` + `github.com/pkg/sftp`（远程）、`gorilla/websocket`（IPC）、
  `gopkg.in/yaml.v3`（配置）、`golang.org/x/sys/unix`（statfs 剩余空间）。
- **密钥不进 YAML**：macOS Keychain（`security` CLI）存密码，YAML 只存 `credentialRef`；
  钥匙串不可用时降级为内存并向前端返回 warning。
- **macOS 12 兼容**：Tailwind 固定在 3.4（v4 需 Safari 16.4）、Vite `build.target: ["safari15"]`、
  `bundle.macOS.minimumSystemVersion: "12.0"`。

### 验证方式（可复用）
- Go：`cd backend && go test ./...`（config/remote/transfer/app 四包，含进程内真实 SSH+SFTP 服务器
  `internal/testutil/sshd.go`）。
- 前端：`npx vue-tsc --noEmit`、`npx vite build`。
- UI 视觉回归：headless Chrome `--remote-debugging-port=9333 --enable-unsafe-swiftshader`，
  CDP 脚本量取 `getBoundingClientRect()` 校验列头/数据行对齐（列头需带 `border-l-2 border-l-transparent`
  才能与行内 2px 选中条对齐）。
- 真实链路：`./src-tauri/target/debug/file-j`，日志出现 `backend listening addr=127.0.0.1:<随机端口>`
  与 `client connected` 即证明 Rust→Go 握手 + 前端 WS 打通；配置落在 `~/Library/Application Support/file-j/`。

### 踩坑
- `cargo build` 会把 sidecar 复制到 `target/debug/file-jd`，调试时它**优先于** `src-tauri/binaries/` 被加载，
  改了 Go 代码只跑 `pnpm backend:build` 不生效，需重新 `cargo build` 或手动覆盖该副本。
- 在受限沙箱里启动 GUI，进程会继承沙箱：`~/Library` 下 rename 返回 EPERM、窗口截图可能拍不到。
  `writeYAML` 已加「rename 失败 → 原地重写」兜底。
- 配置目录里的 `*.tmp` 残留是 rename 被拒时的副产物，正常环境不会出现。
